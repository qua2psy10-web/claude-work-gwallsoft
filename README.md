# 重力式擁壁 設計計算ソフト

道路土工擁壁工指針（平成24年7月・日本道路協会）に準拠した、重力式擁壁（盛土部・直接基礎）の安定計算と設計計算書（PDF帳票）出力を行うブラウザアプリです。ビルド・インストール不要で、`index.html` をブラウザで開くだけで動作します。

## 使い方

1. ローカルで簡易サーバを起動してブラウザで開きます（ES modules を使用しているため `file://` 直接ではなくHTTP経由で開いてください）。

   ```bash
   python3 -m http.server 8000
   # → http://localhost:8000/index.html
   ```

2. 左側のパネルで形状寸法・土砂条件・水位・活荷重・地震時条件・安定計算条件を入力すると、右側に計算書（A4ページ）が即時生成されます。
3. 「印刷 / PDF保存」ボタン（またはブラウザの印刷機能）で PDF として保存できます。
4. 「入力を保存(JSON)」「読込」で入力データの保存・再読込ができます。
5. ツールバーのプリセットから、検証用サンプル4種（水位無/有 × 落差0.27m/0m）を呼び出せます。

## 計算内容

- **躯体自重**: 座標法（断面積・断面一次モーメント・重心）
- **主働土圧**: 試行くさび法（収束精度0.001度）。常時／地震時（物部・岡部型、θ=tan⁻¹kh）、背面水位（水中単位体積重量）、上載荷重（載荷範囲 X1〜X2）、擁壁天端からの落差高さに対応
- **躯体慣性力**: H = V・kh
- **揚圧力**: 台形分布（前面・背面水位差）
- **水圧**: 静水圧（前面・背面）
- **作用力の集計**: 偏心量 e = B/2 −(ΣV・x−ΣH・y)/ΣV、M = V・e
- **地盤反力度**: 台形分布／三角形分布の自動判定
- **安定照査**: 転倒（|e|≦B/n）・滑動（Hu/H≧Fs、水平力0以下は算定不能表記）・支持（qmax≦qa）。常時／地震時で許容値を別設定
- **荷重ケース自動生成**: 水位無→2ケース、水位有→浮力無視/考慮1(前面水圧)/考慮2(背面水圧)/考慮3(前背面) × 活荷重無/有 の8ケース、地震時有効時→常時土圧+慣性力／地震時土圧+慣性力の2ケースを追加

## 帳票構成

サンプル計算書と同じ構成で出力します。

- 目次（ページ番号付き）
- 第1章 設計条件（断面形状図・全体形状図・土砂条件・荷重の組み合わせ表 ほか）
- 第2章 計算結果一覧（作用力・転倒/滑動/支持照査の判定一覧）
- 第3章 作用力の算定（座標法・試行くさび法の公式、ケース毎の土圧計算とω-Pa曲線グラフ、揚圧力・水圧、作用力集計、地盤反力度と反力分布図）
- 第4章 安定計算（照査方法の公式、ケース毎の転倒・滑動・支持照査）

## 検証

計算エンジンは市販ソフトによるサンプル計算書4冊（H=0.85m、水位無/有 × 落差0.27m/0m、計206項目）と照合済みです。

```bash
node tests/verify.mjs
# → 結果: 206 件一致 / 0 件不一致
```


## 適用範囲・注意

- 重力式定型擁壁（前面鉛直・背面直線勾配）、盛土部擁壁、背面土砂レベル（落差高さ対応）を対象としています。
- 転倒照査は偏心距離照査、支持力照査は許容支持力度の入力値照査です。
- 部材計算（竪壁の応力度照査）は条件表の出力のみで、応力度計算は行いません。
- 実務での使用にあたっては、適用条件・計算結果を必ず技術者が確認してください。
